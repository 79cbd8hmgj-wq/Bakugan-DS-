# Gate Card System 2.0 Complete Roster

Milestone 6E converts all 103 Gate IDs into the deterministic seven-archetype framework established by Milestone 6D. The runtime engine, cache, hooks, condition library, effect library, target modes, timing phases, and weighted-selector semantics remain frozen.

## Roster contract

- 103 sorted records using IDs `1..103`.
- No `legacy` archetype records.
- Juggernoid, Gate ID 19, remains byte-for-byte compatible with the approved prototype.
- All records use only Milestone 6D-supported fields.
- Deferred fatigue, activation-limit, history, secondary-effect, and presentation fields remain zero.
- All records have approved metadata and bounded battle weights.

## Balance result

The final deterministic analysis reports no hard duplicate groups, no identical evaluation groups, no identity conflicts, and no unresolved dominance findings. Two potential dominance findings are accepted as explicit tier progression. Juggernoid remains the sole documented out-of-tier compatibility fixture.

## Runtime behavior

The complete roster uses the same emitted ARM module as Milestone 6D. Milestone 6E changes only authored records and metadata. Invalid runtime context remains fail-closed and replays complete legacy behavior where required.

## Deferred work

Ability manipulation, fatigue, activation-history penalties, arena-ID rules, AI evaluation, descriptions, activation UI, and save changes remain outside Milestone 6E. They require separate design gates.
